# Chronetec

Plataforma acadêmica de organização de cronogramas escolares, criada inicialmente para a ETEC Bento Quirino.

## Executar localmente

```bash
npm install
npm run dev
```

## Verificações

```bash
npm run lint
npm run build
```

## Publicação

O projeto é publicado automaticamente no GitHub Pages pelo workflow em `.github/workflows/deploy-pages.yml` após cada push para a branch `main`.
